# Dashboard

A visual dashboard add-on, communicating with the backend

## Installation

Install this mod into Minsky:

```bash
cd /path/to/minsky/modding/tools
bun install-mod.js /path/to/minsky-mods/dashboard
```

Then rebuild/restart Minsky:

```bash
cd /path/to/minsky/gui-js
bun start
```

## Usage

1. Open Minsky
2. Go to **Simulation → Dashboard...**
3. Use the mod
